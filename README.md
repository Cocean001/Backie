# Backie

Backie is a browser-based playground for making animated, diffused gradient backgrounds. Adjust the palette, motion, blend, blur, and composition, then copy the generated CSS or React snippet.

## Development

Requirements: Node.js 18 or newer.

```sh
npm install
npm run dev
```

The development server runs at `http://localhost:3000`.

## Commands

- `npm run dev` starts the Vite development server.
- `npm run lint` runs the TypeScript checker.
- `npm run build` creates a production build in `dist/`.
- `npm run preview` serves the production build locally.

Backie is a client-only app. It does not need an API key, database, or server-side runtime.
